# 温玉灵核 v0.16 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 完成经过源码/竞品研究的离线学习陪伴升级，并验证实际导出包后提交本地 Git。

**Architecture:** 保留 StudyPlan → PlanStore → UI 信号/候选提交；专注与自主动作分别用纯模型。主程序只协调生命周期和持久化，数据文件对话框独立于解析。界面共用玉色 Theme；表现只消费状态。

**Tech Stack:** Godot 4.7.2 / GDScript / Windows NSIS / macOS Universal，现有 Python/PowerShell 构建工具；不增加运行依赖。

**Spec:** `docs/superpowers/specs/2026-10-30-companion-v016-design.md`

## Global Constraints

- 用户已委托方案选择和实施；顺序为获取信息 → 总结 → 修改 → 验证 → 本地 Git 提交。
- 保持三个刚性玉晶部件、内部能量、19 动作、28–72 粒子成长、旧 schema1 计划、手动完成和手动推进。
- 所有写入型验证使用项目内唯一隔离目录；不读取个人 APPDATA，不改真实启动配置。
- 沿用离线 Godot 4.7.2，不引入第三方桌宠代码/美术；不自动推送远端。

## Review Focus

- 导入/导出同路径、文件在确认间变化、主备均坏：不能覆写内部存储或跳过预览确认。
- 已完成最后一项后追加、重复撤销、重复名称：稳定 ID 和手动顺序契约仍成立。
- 系统休眠/时钟变化、重复恢复/结束会话：不虚增或重复结算。
- 隐藏/菜单/手动动作/大字号：新增机制不能抢输入或裁掉保存与退出。
- 新存储保存失败：磁盘与内存状态一致、旧有效备份可用、重试可恢复。

**Produces:**

## Task 2 · 专注和行为纯模型

**Files:** new `study/focus_session.gd`, `pet/ambient_scheduler.gd`, `tests/check_companion_models.gd`。

**Produces:**
- FocusSession fields `state: String`, `duration_seconds`, `remaining_seconds`, `total_focus_seconds: float`, `completed_sessions: int`, `task_title: String`。
- `start(minutes: int, title := "") -> Error`, `pause()`, `resume()`, `cancel()`, `advance(delta: float, continuous := true) -> bool`（仅本次到达 finished 返回 true），`snapshot() -> Dictionary`, `restore(value: Variant) -> bool`（合法才替换，running 恢复 paused）。5–120分钟，delta>2或不连续时暂停。

- [x] 实现模型，不访问文件/节点/业务完成状态。
