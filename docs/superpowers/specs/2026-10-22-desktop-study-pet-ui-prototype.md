# 云龙学习搭子：界面原型拆解

日期：2026-10-22。阶段：视觉候选，不是已实现的 Windows 应用。

用户已确认第一版四状态视觉总览（assets/cloud-dragon/ui/ui-overview-v1.png）作为后续界面布局和配色基线。此确认不等于角色结构、动作或系统功能已验证。

## 外观与姿态的模块化要求

用户要求控件外观、宠物姿态和动作相对独立，方便后续换肤、增加动作。业务逻辑不得直接操纵云龙的身体节点或依赖具体动画名称、素材路径和骨架。宠物表现模块消费语义动作请求，隐藏不同皮肤的节点结构与动画实现；计划界面单独使用 Godot Theme 资源管理颜色、字体和控件样式。

- 业务层只发送 idle、curious、sleepy、celebrate、dragging 等语义动作，不携带任务信息到角色资源。
- PetView 负责加载受信任的内置皮肤、动作名映射、动画播放/中断/结束、回退，并提供气泡锚点与可交互轮廓。
- 每个皮肤包含自己的场景、素材、动画和结构说明；新增动作通过皮肤资源声明，不修改任务进度代码。
- 不同皮肤可以有不同节点或骨架，不能假设四肢骨架可直接复用于所有角色；同一皮肤的各姿态须遵循同一母版与运动约束。
- 第一版要求 idle 可用；缺少可选动作时返回 idle，禁止无穷递归回退。皮肤无效时保持原皮肤，不清除当前任务。
- 外观内容、点击轮廓与气泡锚点使用同一局部坐标系，缩放时一并更新；更换皮肤后刷新窗口包围范围和交互区域，防止挡住桌面或截断画面。
- 换皮肤不修改任务、进度、宠物放置点或用户设置；播放结束时旧皮肤回调不能影响新皮肤。
- 第一版只提供云龙，不提供任意外部资源导入、插件运行、皮肤商城或换肤管理界面。

具体接口与阶段实施范围见实现计划。

## 信息与状态

先拆解界面，不为展示界面而重新设计角色姿态。云龙使用现有漂浮形象作参考，不代表身体结构或动画已经定稿。

- 常驻信息：当前任务名称。不常驻整个清单、进度统计或设置。
- 展开信息：近期目标、当前任务、学习清单和明确的操作。
- 完成状态：任务保持已完成，用户点击“开始下一项”才推进；跨天也不自动推进。
- 设置：开机自启动、宠物显示大小、清单分享与备份恢复；全部为用户主动操作。

## 组件与职责

1. 宠物：身份和陪伴入口，点击展开或收起计划；拖拽改变放置点，不能误触展开。
2. 气泡：一至两行当前任务，完成后改为已完成；完整长标题在计划面板呈现。
3. 计划浮层：在宠物附近显示，按屏幕剩余空间选择方向；空间不足时移动浮层，不能裁掉操作。
4. 设置窗口：独立普通窗口，避免在常驻区域堆积表单；原型展示设置页面状态。

## 四个展示画面

### 常驻桌面

低干扰桌面背景、无宠物外框、一个紧凑目标气泡“当前：单例模式”。不显示清单或固定操作栏。桌面背景仅作使用环境示意，不是产品自带全屏窗口。

### 展开学习计划

标题“学习计划”，显示目标“每天学习一个设计模式”，当前任务“单例模式”，主按钮“标记完成”，示例清单为单例、工厂、策略、观察者模式。设置入口和收起入口为次要操作。四项仅是原型演示数据，不是强制内容。

### 完成后等待推进

保留当前任务，明确显示“单例模式已完成”；主按钮“开始下一项”。不暗示已自动切到工厂模式。宠物本轮不新增庆祝姿态或特效，仅用文本状态表达，动作另行按结构流程设计。

### 设置

自启动开关默认关闭；显示大小选择；“分享清单”和“备份与恢复”分别呈现。导入替换前确认和错误状态在后续交互稿补充，不伪装为已实现。

## 视觉方向

奶白和浅蓝呼应云龙，深蓝灰文字保持对比。紧凑圆角浮层、克制阴影，不采用密集仪表盘。图标不替代关键操作文字。先采用浅色候选；深色、长文本、窄空间和键盘焦点在后续可交互稿中检查。

## 验收边界

本轮输出静态界面状态总览供审阅，不声称支持点击、保存、系统自启动或动画。方向确认后才细化可交互原型。透明区域输入、窗口遮挡、DPI 和资源占用需 Godot 技术原型独立验证。
