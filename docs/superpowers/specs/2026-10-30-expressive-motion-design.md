# 温玉灵核：动作与情绪互动升级

依据：[热门产品机制与动画原则研究](../../research/2026-10-30-expressive-interactions.md)。Steam 评价与 GitHub 星数只能表明产品热度，不能作为单个动作的排行榜。采用即时反馈、指针关注、亲昵回应、安静休息，以及预备/错峰/缓动原则。

方案选择由代理负责：在当前三块刚性玉晶上增强可读情绪，不更换主体形象。新增 greet 招手、nuzzle 亲昵、startle 惊喜、doze 打盹；分别约3.4/3.8/2.8/6.4秒。每个动作都有预备、主要意图、短暂强调、过冲与收势；七条既有姿态通道首尾归零，持续悬浮相位不重置。已有感知/舒展/收息在安全边界内细化。

交互：靠近时柔和注视；停留约1.2秒可招呼一次；在玉核上左右轻扫形成亲昵，快速靠近可有克制惊喜；双击招手，中键亲昵。所有自动反应有至少6秒冷却，悬停不连续重复，首次取样/抖动不误触。菜单、拖动、面板、隐藏、专注、安静/减少动态时不主动触发，不抢用户动作；休眠不补发。单击动作循环与引光打开计划保留。

纯 SocialInteraction 模型只接收时间和相对指针，不访问 OS 或学习数据；main 统一选择指针/图标关注后只写一次朝向。动作沿用相同 rig，2D/3D一致；不新增石体、扩大粒子路径或拉伸几何。

验收：纯模型的停留/轻扫/冷却/阻塞/长间隙；动作可用、节奏、首尾、刚性、石体不穿插、边界、30/60/120Hz返回；旧回归、实际GPU23动作透明裁切及2D/3D投影；实际预览、EXE构建、独立审查、本地Git提交。不把产品热度或有限GPU样本当作所有动作质量/全部设备兼容的保证。
