# Windows 开机自启动

用户要求在分点提交既有改动后增加开机自启动支持。设置页现有禁用占位项改为可操作开关，默认不主动开启，含义为当前用户登录 Windows 后启动桌宠。

采用当前用户 Startup 目录中的 `WarmJadeStudyCompanion.lnk`，通过系统 PowerShell 和 WScript.Shell 创建快捷方式，直接指向当前导出的 EXE，并设置正确工作目录。无需新依赖、管理员权限或后台服务。相较 HKCU Run 注册表，该方式可以直接查看、移除；不采用需要提权的全用户启动目录或计划任务。

界面每次打开读取快捷方式实际存在状态。启用、禁用失败时显示错误并恢复真实开关状态，不把未成功的操作保存为偏好。非 Windows、编辑器运行及隔离数据测试模式不可配置真实系统启动。测试通过显式临时 Startup 目录操作真实快捷方式，不改用户系统配置。移动或删除 EXE 后，应在新位置重新开启；系统策略或任务管理器可独立禁用自启动。

保留学习数据目录、单实例保护与当前温玉灵核版本启动入口。交付新的可执行文件和独立功能提交；不替用户自动开启开关。
