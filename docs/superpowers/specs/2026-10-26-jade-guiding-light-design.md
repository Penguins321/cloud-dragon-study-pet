# 引光改为聚光成笺

用户反馈烟雾很奇怪，要求重新设计引光。现有实现仍在复用玉龙喷气噪声与多层云团，与玉核形象不协调。本次直接替换为细暖金引线与半透明薄玉色光笺，继续显示真实目标并支持点击展开计划。

动作：0–0.6 秒内光蓄亮、主核微升且保持正立、两片打开；0.25–1.2 秒顶部细光带牵引光点、展开左上方光笺；1.05–5.1 秒稳定阅读，光带淡去；5.1–5.6 秒光笺淡出、光点沿引线收回。最后所有偏移归零，连续回悬浮，不重置相位。

复用既有目标文字布局、5.6 秒时间线和点击接口。玉核使用独立 goal_light.gd，旧龙保留原烟雾。无需新依赖。保留所有缩放、完整窗口边界、透明轮廓覆盖与原学习数据。

实施与验证：先增加 smoke-free / 展开前不可点击 / 结束无残留 / 四档缩放边界检查并确认失败，再实现光笺、接入 main、修改动作峰值；全量回归、渲染阶段图、导出新 EXE 验证。替代方案为仅降低烟雾浓度，但仍保留喷烟观感，因此不采用。
