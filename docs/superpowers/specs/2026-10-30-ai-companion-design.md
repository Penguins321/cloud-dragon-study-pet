# AI 自主动作与简短气泡方案

## 已确认的目标

用户希望接入 DeepSeek 或 OpenAI，根据桌宠状态自主选择现有动作，并同时增加简短文字气泡。沿用当前 Godot 桌宠和四个伙伴。

## 接入方式与取舍

建议采用桌面端直连 API：用户在设置 → 陪伴中选择服务商、模型并填写自己的 API Key。现有离线行为作为关闭、未配置、断网和出错时的回退。另一方案是统一后端代理，适合后续统一账号、用量管理和公开分发；本轮不新增该服务。

用户已选择桌面直连，并明确要求密钥写入本机配置、重启有效且不上传 Git。配置独立保存为用户数据目录下的 `ai_private.cfg`；不混入 preferences.cfg、学习备份或日志。默认以明文本地保存，设置中明确提示；保存时原子替换，不创建密钥备份，POSIX 平台尽量限制文件为当前用户读写。Git 忽略 ai_private.cfg 及其临时文件；所有导出 preset 明确排除私有配置。


## 使用体验

- AI 陪伴默认关闭；开启前展示会发送的状态摘要。设置提供服务商、模型、密钥输入、测试连接、动作+气泡开关与状态提示。
- 默认只发送当前角色、是否正在专注、闲置时长区间、最近动作及事件类型，加上用户已保存的偏好与角色性格；聊天另外发送最近对话。不上传屏幕、文件、学习目标或任务标题。
- 默认每 120 秒最多发起一次自主决策；事件可以成为下一次决策的原因，但不突破限频。单次请求超时 10 秒；不并发，不连续重试轰炸服务商。
- 模型输出 action 和 text；action 必须属于当前角色可用的自主动作白名单，允许 idle／不动作。text 可以为空，建议最多 24 个字符，禁止脚本、富文本命令或外部链接。
- 气泡为浅玉色，最多两行，默认显示约 6 秒后消失，一次只显示一个，可关闭。使用独立、无边框、不抢焦点的小窗口，随伙伴定位并限制在屏幕可用区域内，避免改变主窗口大小导致伙伴跳动。
- 语气温和、简短，不催促、不贬低、不声称能看见用户或读取未发送的内容。
- 点击／拖动即时响应由本地完成。隐藏、安静、减少动态、专注中、打开面板和菜单时不主动打扰；请求返回后重新检查状态，不播放过期动作或气泡。
- 切换角色、关闭 AI、隐藏桌宠、开启专注或退出时，取消／作废尚未完成的决策，及时清除气泡。

## 实现边界

复用 ambient_scheduler 的调度入口、现有动作播放、字体缩放和窗口几何策略；新增独立 AI 请求／决策模块与文字气泡组件，不把模型响应当代码执行。接口错误、超时、空响应、格式错误或非法动作均回退本地，不更改学习数据、不抢占当前动作。

用户后续已明确增加连续聊天、上下文、用户偏好与稳定伙伴性格。每个角色保存最近 20 轮、发送最近 12 条消息作为有界上下文；最多20条显式长期偏好与600字角色性格。私有 ai_memory.json 持久保存，排除 Git／分发／普通备份。可查看、编辑、删除记忆；清空当前角色对话需要确认，不删除偏好与性格。记忆只自动接受当前用户消息的明确偏好摘录，不推断私人事实。

用户又明确选择新的交互：轻点伙伴先回应并浮现一句短话，点短话展开聊天；查看学习目标使用独立菜单。原引光纸笺和连接线撤除，仅保留短暂光效。聊天面板继续沿用浅玉主题与统一顶部栏。手动短句在安静、专注或减少动态时仍可使用，自主短句遵循勿扰。

不增加语音、不读取桌面内容，也不要求 AI 生成新动画。自主回应允许完全静默。

## 验证

使用假 HTTP 服务／可注入响应验证两种服务商的请求、响应解析、限频、超时、旧请求作废、非法动作和密钥不泄露；真实渲染验证两行文字、各字号、四角色、窗口边缘与不同缩放的裁切。运行现有回归并构建。未配置真实密钥时明确区分模拟验证与真实 API 验收。
