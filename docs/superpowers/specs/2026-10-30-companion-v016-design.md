## 目标与边界

交付一次完整 v0.16：用户可以维护原有进度、开始可恢复的专注、按需要调整陪伴强度、主动分享和恢复计划，且界面与角色状态一致。

Godot 4.7.2 / GDScript，沿用当前离线单进程架构。保持三个刚性玉晶部件、内部能量、19 动作、28–72 粒子成长、旧 schema1 计划、手动完成和手动推进。成长仍表示可见陪伴时间，专注统计另算。使用自有程序化图形和现有资源，不复制竞品代码/素材。

本轮不建设账号、云同步、AI 聊天、商城、外部插件、全局键盘监听或新角色体系。Mac 真机、多屏/DPI 与历史长帧的外部验证不虚称完成。

## 1. 计划与数据

### 日常维护

- 追加任务：1–200 字、总量最多 500；保持已有 ID、当前项与完成状态。空清单追加后成为当前项。
- 修改当前任务/近期目标：原位改文字，保持任务 ID/顺序/进度；目标最多 300 字。
- 撤销当前项完成：仅撤销当前项，已推进的前序项不变；不自动后退。
- 原“每行一项”的整单替换仍有明确确认，文案说明会重置进度；追加和修订是更常用的入口。
- UI 继续发信号；用候选计划先保存成功，再换内存状态/庆祝。

### 分享与恢复

- 清单分享文件只带目标和任务文本；计划备份带当前项和完成状态。两者均有独立 format/version，最大 2MB；未知版本、错误类型、过量/过长内容拒绝。
- 文件导入先解析、展示类型/目标/数量/已完成数，再确认；取消不写入。确认使用已预览的内存快照，避免文件在确认间被替换。
- 覆盖前保留当前有效计划到独立 `plan.json.before-import`；常规 `.bak` 仍表示前一次有效保存；分别提供恢复最近备份、恢复导入前计划入口。
- 导出不得覆盖当前计划、偏好及其临时/备份/检查点文件。
- 主备均损坏继续阻止普通写入并保留原文件；数据页给出数据目录入口与可操作说明，不能静默重置。
- “计划备份”明确只包含学习计划和进度。偏好、系统启动配置、窗口绝对位置不随清单分享文件迁移。

### 偏好可靠性

新增小型 PreferencesStore：`.tmp` 写入/flush 后替换，保留有效 `.bak`；主损坏可回退，不用损坏主文件覆盖有效备份。配置含现有外观/字号/成长和新增会话/陪伴设置；保留未知配置字段。读取非法数字/枚举时使用安全默认值，写失败保留待保存标志并显示可重试错误。

执行裁定：偏好主备均损坏时保留两份原文件，用默认值运行并阻止自动保存；导入检查点也采用临时写入替换，检查点失败中止导入，允许检查点成功而后续保存失败，但原计划与内存不变。

## 2. 专注会话

- 独立纯模型，状态 `idle/running/paused/finished`；默认 25 分钟，允许整数 5–120 分钟。支持开始、暂停、继续、结束本轮/重置。
- 开始时记住当前任务标题快照，无任务用“自由专注”。计时不修改任务；标题变更/手动推进不暗中重绑已开始的会话。
- 使用连续时间增量；无效/非有限增量拒绝；超过 2 秒的运行间隙视为挂起并暂停，不补算睡眠时间。重启恢复为暂停，需手动继续。
- 用户主动隐藏宠物只隐藏角色，会话继续；暂停/退出/休眠不虚增专注。模型可保存/恢复，并校验时长、状态、统计。
- 累计专注秒数按实际运行增量增加；完整计时结束时会话计数仅加一次，取消不假称完成。与陪伴成长独立展示。
- 结束只更新状态文字，角色可在可见、非静默且未忙时轻微回应一次，不弹强制窗口、不播放声音、不自动完成或推进任务。

## 3. 形象与自主陪伴

- 添加独立 AmbientScheduler，45–90 秒可控随机冷却，选择感知/收息/舒展/巡光，避免连续相同动作。隐藏、菜单、拖动、打开面板、手动动作、专注时不调度；解除阻塞重新等完整冷却，不补发。
- 陪伴档位：`natural` 自然陪伴（默认）、`quiet` 安静悬浮。用户点击预览仍可用。
- “减少动态”：自动表演关闭、基础悬浮/粒子相位更缓慢；手动预览保留。状态表达依靠文字和稳定内光。
- 专注运行时抑制自主表演与图标避让，核心内光更稳定克制；暂停/结束平滑恢复。不得用石体缩放、额外白色石柱或更多装饰表达状态。
- 外观页保留实时预览与全部材质/颜色/动作；补充语义化一键组合和清楚的当前选择。

## 4. 界面与桌面控制

- 学习计划和设置共用浅玉色、暖白卡片、深青正文、同一主按钮/焦点风格；减少蓝色旧主题残留。
- 学习页结构：目标与当前项 → 完成/撤销 → 专注卡 → 总进度/任务列表 → 追加/修订/整单替换。长内容可以滚动，大字号保留全部操作。
- 设置页采用“外观 / 陪伴 / 桌面 / 数据与帮助”分类，避免长串卡片；动作预览可归组。四档字号同步到新增按钮/输入/弹窗。
- 首次创建示例计划时打开学习页并给出简短操作提示；帮助可重看。老用户不反复弹欢迎页。
- 设置/计划按 Escape 收起，Tab 能到主要控件；不宣称未验证的读屏标准兼容。
- 新增置顶开关，默认保持现状 true；关闭后周期检查不再强制置顶。提供“找回宠物”从托盘恢复并夹取工作区。
- 性能档位 `smooth` 60FPS（默认）、`eco` 30FPS；隐藏继续使用既有暂停/低处理器策略，显示恢复用户档位。设置页明示档位，不能用减少动画代替透明区域校验。

## 5. 验收

1. 旧计划/偏好重启可用；追加、修订、撤销不重置前序进度。
2. 导入取消/非法文件/未知版本/失败写入均不替换计划；覆盖前检查点可读取，主备损坏不静默覆盖。
3. 偏好损坏回退、失败保存、非法值、会话重启暂停与重复结束均有行为测试。
4. 自主调度冷却/阻塞/睡眠无补发；静默/减少动态/专注状态统一生效；手动操作优先。
5. 正常/最大字号、窄窗口、长任务、文件预览、所有分类真实渲染；新增纯键盘路径验收。
6. 现有完整回归、19 动作透明裁切、2D/3D 对照、能量/折射检查继续通过；记录新功能的 GPU 与帧时证据。
7. 生成 Windows EXE/安装/便携包和 Mac ZIP，验证实际导出功能、字体、资源；隔离安装卸载。Mac 本机运行仍待真机。
8. 最终独立审查、文档更新、干净本地 Git 提交；不自动推送远端。
