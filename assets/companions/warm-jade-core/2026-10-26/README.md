日期：2026-10-26。用户明确选定六款简洁玄幻候选中的 **E 温玉灵核**，理由是动作设计最简单，并要求开始细化。不再继续扩散其他形象。

## 结构先行

唯一结构为 **主玉核 + 左伴生玉片 + 右伴生玉片 + 内光遮罩**。前三者是刚性物件，内光是材质 / 效果层，不是第四块石头；不增加眼嘴、手脚、翅膀、法环或花纹。两枚玉片故意悬空，属于伴生物，不当作脱落的手臂。

主核是短宽菱体，四至六块大切面，温润浅玉色；伴生片各保留约三块切面。中央暖金 / 象牙白光缝作为状态表达，不能画成主核被劈开的实体裂口。光效不应遮盖外轮廓或把主体变成强光球。

动作中三个刚体各自只平移、旋转，不弯曲、不非均匀拉伸、不改变棱面。两片不互换左右、不绕到主核背面、不插入主核、不出现额外碎片。运行几何应校验各多边形最小间隔；图示的开合距离不是碰撞验收结果。

初步比例以主核高度 H 为单位：宽约 0.55H；单片高约 0.28H、宽约 0.12H，默认中心在左右约 0.48H、向下约 0.12H。所有尺寸和运动相对 H 描述，换色和缩放继续复用。不要把这些艺术控制量称为已完成真实力场仿真。

## 从结构推导动作

| 动作 | 主玉核 | 伴生片与内光 |
| --- | --- | --- |
| 悬浮 | 缓慢小幅升降，轻微整体倾斜 | 两片错相悬浮；内光缓慢起伏，不改变石体大小 |
| 巡游 | 小范围水平偏移，向运动方向略倾 | 两片稍迟跟随，整体仍处于拖动边界内；不自动跨屏漫游 |
| 感知 | 向目标方向轻倾约 8° 后停留，再回中 | 两片保持侧别并稍迟响应，不新增表情 |
| 舒展 | 主核略抬、回正 | 两片向外展开、略升高，光缝稍亮 |
| 收息 | 主核略降，缓慢回正 | 两片靠近下侧但始终留缝，内光变弱 |
| 共鸣 | 小幅抬升后平稳回落 | 两片上展，暖光一次渐亮后回落，不使用碎片爆炸 |
| 引光 | 主核微倾向左上方 | 从顶部挂点引出独立淡玉暖白光雾，成幕后显示今日目标，结束后消散 |
| 牵引 | 拖动时整体跟随指针，不增加形变 | 两片轻收，释放后回悬浮；拖动不消耗点击动作 |

先由主核动作建立方向感，伴生片分别落后约 0.07 / 0.12 秒，表现跟随；这些是表现节奏，不是三个物件撞在一起的机械关节链。动作切换使用连续缓入缓出，切换不归零当前浮动相位。初版不做翻身、全周旋转、石体裂解与组合变形，以免需要背面补画和额外遮挡关系。

## 与既有产品的对应

保留 Godot + GDScript、独立皮肤 / 动作 / 学习数据模块。新角色单独实现三个刚性部件，不继承旧龙的 46 关节权重。旧云龙皮肤和档案继续保留。

原语义动作可对应：`idle` → 悬浮，`swim` → 巡游，`look/curious` → 感知，`stretch` → 舒展，`rest/sleepy` → 收息，`celebrate` → 共鸣，`dragging` → 牵引，`breath` → 引光。`breath` 仅作为兼容语义名，用户界面不能继续显示“玉核吐息”。

仍保留右键菜单、目标不常驻、点击循环动作、50% / 75% / 100% / 125% 缩放和完整动作边界不越屏。引光源从角色顶部挂点计算，不沿用龙嘴坐标；光雾向左上 45° 形成目标背景，文字仍取真实当前学习项，不与美术烘焙。此前的完成 / 手动推进规则和个人进度不因换形象重置。

下一阶段接入前需落实：同一母版的三个透明部件与光层、枢轴、全动作包围框、独立部件的显示 / 点击轮廓变换、切换连续性与屏幕边缘覆盖。不能因几何结构简单就跳过窗口裁剪和透明区域验收。
