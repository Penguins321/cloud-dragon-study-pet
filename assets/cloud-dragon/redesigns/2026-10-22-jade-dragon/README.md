# 玉骨天龙 · 美术重设计

日期：2026-10-22。用户要求：可以减少亲和感，需要更高级、更有玄幻色彩；线条不必柔和。三方向对比后，用户明确选择 **C 玉骨天龙：清冷古雅，更像上古神兽**。

## 先拆解的约束

1. 长吻与窄眼组成成熟头骨，骨角固定于颅骨；角与鳞甲不能像软毛一样随风抖动。
2. 一条连续的头—颈—肩—胸腰—骨盆—尾脊柱，浅 S 悬浮，避免盘绕与身体交叉。
3. 严格四肢：前肢从肩带连接，后肢从骨盆连接；每肢明确上段、下段、腕踝与爪。近远侧固定遮挡，先保证一眼能追踪连接。
4. 两条龙须分别固定于口鼻 / 面颊，沿连续曲线向末端传递摆动；须不从角、鬃毛或空中长出。
5. 玉白 / 青玉为主体，少量淡金骨脊。硬质鳞甲使用明确折线与平面，鬃毛用较长、较少的锐形组块，避免把“高级”变成密集小花纹。
6. 风动分区：头骨、角、眼、鳞甲是硬区；须、鬃毛、尾焰是柔性跟随区。刚柔区域需在最终分层素材中分离，不能把硬角拖成布条。
7. 50% 桌面尺寸首先保留轮廓、眼神、角型与爪形；鳞片细节服从大形，不依赖海报尺寸才可辨认的线条。
