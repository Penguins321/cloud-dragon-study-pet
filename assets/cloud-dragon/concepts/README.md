用户要求所有设计先拆解，再按现实结构与运动规律设计新姿态或动作。新稿必须先建立部件连接、固定比例、关节和身体中心线，再做无装饰姿态与连续关键帧检查，最后添加外观细节。漂浮是明确的奇幻设定，不能作为身体连接、比例或运动连续性错误的理由。现有图片仅作视觉参考，尚未通过统一结构母版验证。
