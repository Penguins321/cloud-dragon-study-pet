# 姿态结构探索

`pose-structure-study-v1.png`：2026-10-22 使用内置 imagegen，根据现有 `desktop-pet/pet/skins/cloud_dragon/dragon.png` 外观参考生成。原图保留；本图是新增候选，不替换运行素材。

三行分别为舒展漂浮、收拢休息、警觉抬头；每行左右是结构示意与外观。设计依据见 [动作拆解](../../../desktop-pet/docs/motion-design.md)，完整提示词见同目录 `pose-structure-study-v1-prompt.txt`。

初步检查：本版没有盘绕、自交或独立多段身体，头至尾能够连续追踪，每行保留两前肢与两后肢，肩部与骨盆分别标记。但草图仍带鬃毛等装饰，尚非正式骨架图；各行脊柱长度、胸腔与骨盆坐标尚未统一量化，远侧前肢遮挡也需在拆层时明确。因此只能作为用户姿态审阅候选，不能直接切成动画帧或宣称结构已定稿。

接入前：用户确认姿态 → 无装饰母版统一长度与关节标记 → 对照外观确认四肢连接和遮挡 → 分层 / 逐帧制作 → 更新皮肤轮廓策略 → 动画与各档缩放回归。
