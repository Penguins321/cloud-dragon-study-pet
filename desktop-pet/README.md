# 云龙学习搭子 · Windows 交互原型

Godot 4.7.2 标准版，GDScript。当前是可运行原型，不是正式安装版。

## 启动与操作

运行 `build/CloudDragonPrototype.exe`，或项目根目录的“启动云龙原型.cmd”。不需要安装 Godot。

- 左键点击云龙或气泡：展开/收起学习计划。
- 按住左键拖动超过 8 个逻辑像素：移动宠物，释放后不打开计划。
- 右键云龙：打开学习计划。
- “标记完成”只完成当前项；点击“开始下一项”才推进，不随日期自动推进。
- “编辑清单”可修改近期目标及任务，每行一项，替换前确认并重置进度。
- 设置可切换小/中/大三档显示大小。
- 托盘左键恢复，右键打开菜单；“隐藏宠物”最小化至托盘。无托盘支持时保留计划入口，避免宠物无法找回。
- 退出使用设置或托盘中的“退出”。窗口可被其他应用遮挡，Win+D 后不保证仍显示。

开机自启动、清单分享、备份恢复界面明确标记为待产品化，未实现。内部自动保留上次有效学习数据备份；此备份不等于已经实现用户导入导出。

## 数据

正常运行默认保存到 Windows 用户数据目录 `CloudDragonStudyPrototype` 中的 `plan.json`、`plan.json.bak` 与 `preferences.cfg`。不写入安装目录，也不要求联网或账号。

测试时使用 `CLOUD_DRAGON_DATA_DIR` 隔离数据，不触碰正常用户进度。损坏主文件可恢复备份；主备均坏时不覆盖文件，界面报告错误并暂停保存。首次无文件时创建四项设计模式演示清单，用户可自行替换。

## 皮肤与动作模块

`pet/pet_view.gd` 是业务唯一的宠物表现入口；`pet/pet_skin.gd` 定义内置皮肤数据。`pet/skins/cloud_dragon/` 自包含场景、素材和语义动作映射。界面控件样式位于 `ui/study_theme.tres`。

新皮肤先拆解并校验自己的身体结构，再提供场景、AnimationPlayer 路径、动作映射、局部包围框、点击轮廓和气泡锚点。不同角色不要求共享骨架；新增动作通常不修改学习模型。idle 为必需动作，其余缺失时安全回退。第一版无外部皮肤导入或切换菜单。

当前云龙只有静态 idle，透明 PNG 是从既有候选图经内置 imagegen 提取的原型素材，不是已通过统一骨架验证的正式动作资产。保留原图，后续更改另存版本。

同一数据目录使用进程生命周期内的 localhost TCP 绑定防止重复写入，不传输学习数据、不对外监听。端口被占用时安全退出，不绕过保护；两个不同目录极少数哈希碰撞也会拒绝启动，后续产品化可改用 Windows 命名互斥量。

## 开发、测试与导出

使用本工作区 `../.tools/godot-4.7.2/Godot_v4.7.2-stable_win64_console.exe`。引擎和 Windows 调试模板均来自 Godot 官方 godot-builds 发布，记录见 `docs/verification.md`。便携引擎只用于开发，不随原型分发。

从项目父目录执行 `./test-prototype.ps1` 可运行全部回归检查，使用独立测试目录。执行 `./build-prototype.ps1` 导出 Windows 原型并生成引擎许可说明；构建需要先准备 `.tools` 中的引擎和模板。

`Windows Validation` 是独立的测试导出预设，只改变入口并打包测试脚本，用同一批生产代码运行烟雾测试；不应把验证版当作产品分享。测试发出真实控件信号并检查状态，不能代替真实鼠标拖拽、桌面穿透和托盘菜单操作。

## 验证状态

详见 `docs/verification.md`。源码与导出验证版已在当前 Windows/OpenGL 环境运行。多屏拔插、不同 DPI、其他显卡、Windows 10 和真正鼠标输入的验收仍未完成。
