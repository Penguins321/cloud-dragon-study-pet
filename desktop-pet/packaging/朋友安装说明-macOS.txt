温玉灵核 · Mac 朋友试用版

1. 双击解压整个 ZIP。
2. 把 WarmJade.app 拖到“应用程序”文件夹。
   更新时先在旧程序里点击“退出”，再用新应用替换旧应用。
   不要同时保留两个同名应用分别运行。
3. 在“应用程序”中双击 WarmJade。
4. 若提示无法验证开发者，先关闭提示，再进入：
   苹果菜单 → 系统设置 → 隐私与安全 → 找到该应用 → 仍要打开。
   仅在确认此文件确实由朋友提供且没有被修改时操作。
   不要关闭系统安全保护。公司管理的 Mac 可能禁止手动放行。

不需要安装 Godot、Python 或开发工具，不需要 Apple 开发者账号。
本版设置页顶部应显示“版本 0.16 · 按自己的节奏，相伴学习”。
顶部没有这行字，就仍然打开了旧版；请从“应用程序”重新打开替换后的应用。
本包使用本地签名，没有付费 Developer ID 签名和 Apple 公证。

系统要求：Apple Silicon（M 系列）macOS 13 或更新；Intel macOS 11 或更新。
首版尚未完成 Mac 真机验收，请作为试用版；桌面图标感知暂不支持。

待 Mac 真机验收：
- 切换四档字号，检查设置、学习计划、编辑页、确认弹窗及新生成任务。
- 检查 3D 晶体、内部光芯、跳跃/舞蹈/游动与拖动；本版已移除火焰。
- 检查 3D 开关、透明背景、窗口置顶、隐藏恢复与登录自启动。
打包时已检查最终应用资源和字体同步，但 Windows 上的检查不替代 Mac 真机测试。

操作：轻点宠物切换动作，拖动调整位置；右键菜单或菜单栏图标打开设置。
如需开机启动，先放到“应用程序”，打开设置启用，下次登录生效。
隐藏后可从菜单栏恢复；退出请使用应用菜单中的“退出”。
卸载前先关闭应用内自启动，再退出并把应用移到废纸篓。

遇到问题请把 macOS 版本、芯片型号和完整提示截图发回；
不要把“已损坏”或“含恶意软件”提示简单当作普通开发者提示忽略。
