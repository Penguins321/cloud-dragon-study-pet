# 玉骨天龙：结构、头部、风动与吐息

日期：2026-10-22，对应 v0.5。用户选择 C 玉骨天龙，要求清冷古雅、线条利落。默认朝左，采用不交叉的浅 S 悬浮姿态；先检查头颈、肩、骨盆、四肢和尾根，再允许增加动作。旧盘绕候选不作为绑定参考。

## 模块与复用

| 职责 | 位置 | 复用边界 |
| --- | --- | --- |
| 学习数据与手动推进 | `study/` | 不感知角色、骨架或雾幕 |
| 语义动作、点击循环、优先级 | `pet/pet_view.gd` | 缺失动作安全回退，旧皮肤仍有五个点击动作 |
| 玉骨比例、权重、硬区、软鬃 | `pet/skins/jade_dragon/rig.gd` | 继承旧驱动，各实例拥有自己的关节数据 |
| 普通动作时间线 | `pet/motions/cloud_dragon_flexible_v2.tres` | 换色继续共享，不复制关键帧 |

| 闭眼与尾焰明暗 | `pet/skins/jade_dragon/flame.gdshader` | 独立材质；眼睑只覆盖局部，保持源 alpha 和调制色 |
| 喷流、雾幕、目标文字 | `pet/effects/goal_breath.gd`、`cloud_mist.gdshader` | 主程序只传入口部位置、大小、时刻、当前任务标题 |

仅换颜色可复用骨架、动作库、相位、延迟和效果时序。头部闭眼色也保留实例调制；若用新贴图局部重绘颜色，需同步闭眼素材及源纹理轮廓。若改变身体比例、角型或须根，必须重新绑定和验证，不能直接替换 PNG。雾色目前在效果 Shader 与绘制颜色中定义为灰白、青玉阴影，改变配色时一并调整，不复制动作规则。

## 结构与控制链

透明源图 1983 × 793，对应局部 440 × 175.95562；55 × 30 网格，1736 个顶点、3300 个三角形，每顶点最多四个归一化权重。共 46 个控制关节，保留既有语义索引；父子计算按拓扑排序，不假设关节 ID 天然排序。

| 部位 | 绑定坐标示例（未镜像的源图局部坐标） | 约束 |
| --- | --- | --- |
| 主轴 | 肩 `(350,124)`、胸 `(300,127)`、腰 `(245,113)`、骨盆 `(200,103)` | 连续传递弯曲；骨段不缩放 |
| 颈头 | 颈 `(372,91)`、头 `(399,60)` | 头骨、骨角和眼鼻为硬区，不能随软毛扭曲 |
| 四肢 | 近前 `(350,128)`、远前 `(372,127)`、近后 `(195,107)`、远后 `(216,111)` | 前肢接肩、后肢接骨盆；当前固定近远遮挡 |
| 五段尾部 | 根 `(154,119)` → `(123,131)` → `(91,129)` → `(62,115)` → 梢 `(36,97)` | 父链顺序传递，末端有延迟和附加细波 |
| 尾焰 | 根 `(30,94)`、焰身 `(31,67)`、主尖 `(29,25)`，左右火舌各两节 | 焰身跟尾梢，火舌相对焰身继续变化 |
| 双须 | 口部两处根分别 `(420,75)` / `(407,75)`，各四点连续链 | 固定须根；源图细须重叠，使用平滑混合，避免大幅抬颈时翻折 |
| 软鬃 | 颈 `(365,82)`、肩背 `(287,112)`、腰背 `(239,93)`、髋侧 `(194,90)`、尾部 `(140,119)` | 各自接身体对应骨段，各有独立末端；不从空中长出 |

五组身体鬃毛依次错相 0.7 弧度，主幅度 4 / 3.5 / 4 / 3.5 / 3 度，叠加较小二次谐波。它们是局部软区影响场，未把整段鳞甲当布料。新素材须长、头骨窄，双须与抬颈相对旧驱动分别校准为 0.5 / 0.6 增益，防止细网格翻折。尾部、双须与焰尖的基础传递规则延续 [v3 手册](wind-and-tail-v3.md)。

相位持续累计、切换参数混合 0.25 秒，不因点击动作重置。眨眼使用独立 16 秒时钟，间隔不等：快速闭合、短停、较慢睁开。隐藏时身体、须、鬃、焰与眼睑均暂停。当前整体网格可以表现受约束的小幅变形，不能代替独立拆层和全身动力学求解。

## 云雾吐息

点击顺序为游动 → 抬头 → 舒展 → 收拢 → 欢腾 → 吐息。右键菜单可直接调用吐息。源图口部锚点 `(419,73)` 经同一骨架变形和镜像变换取得屏幕坐标，雾团中心始终相对口部向左上 45°。

| 时间 | 动作与效果 |
| --- | --- |
| 0–0.35 秒 | 略抬颈、收身准备，尚无文字 |
| 0.35–1.05 秒 | 连续云雾从唇线喷出，逐渐扩散、卷动、凝聚 |
| 1.0–1.25 秒 | 雾团形成后目标文字渐入 |
| 1.05–1.6 秒 | 喷流逐步停止，雾团继续缓慢卷动 |
| 5.1–5.6 秒 | 雾与文字一起消散，回到悬浮 |

喷流包含 26 个依次发出的雾团，离口后扩散并横向涡动。目标雾幕由主云层和九个错位云团组成，三层噪声与域扰动产生细碎卷流和密度变化；阴影偏青玉，亮部灰白，避免光束、硬卡片与高饱和蓝色。它是实时二维程序化云雾，尚非体积流体模拟。时间显式来自当前动画，不使用全局 TIME，暂停、拖拽打断和离线预览保持一致。

今日目标平时完全隐藏；雾幕文字来自当前学习项，不硬编码为“单例模式”。点击雾幕进入计划，不自动标记完成或推进。最小 50% 尺寸目标字号至少 14；过长标题至多两行并省略，完整内容在计划查看。当前没有独立下颌张合层，采用唇线呼雾，不宣称已有完整张口动作。

## 显示边界与验证

Windows 原生轮廓同时裁剪画面。使用源 alpha 轮廓、网格细分与同一骨骼插值，身体与效果先做并集，最后用零宽连接拼成单个轮廓。原生多边形采用 ALTERNATE 填充，重叠轮廓直接拼接会切出孔洞，依据 [Godot Windows 实现](https://raw.githubusercontent.com/godotengine/godot/master/platform/windows/display_server_windows.cpp)。布尔合并引入的小数边再经过原生取整也可能裁边，故在屏幕坐标扩展 2 像素后并集；保留独立透明区域，微小封闭空隙保守填充。不要改成整个窗口捕获点击。

固定动画包围框预留左上雾幕，动作中不改变窗口尺寸；每帧拖动夹取整个窗口到屏幕工作区。原生区域只在效果开始、阶段变化或角色移动超过阈值时重建，绘制保持连续。
