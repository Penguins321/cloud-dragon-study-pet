# v0.11 桌面图标感知与大动作

## 桌面图标

通过 Windows 的 UI Automation / MSAA 无障碍接口读取 Explorer 桌面图标的屏幕矩形；当前机器 UIA 没有暴露子项，MSAA 兼容路径实际读到 41 个矩形。没有读取图标名称、文件内容或屏幕截图，没有打开、移动或点击图标。

“桌面图标感知”在设置页可以开关并保存。仅在真正的桌面位于指针下方时回应，其他应用覆盖的图标不会触发。指针停在图标附近时，空闲玉核缓缓倾向它；退出目标后自然回正。主动播放动作时不会被转向打断。

玉核的动作预留区域与图标重叠时，会尝试在附近寻找空位，缓慢移开。每次位移最多约 260 px，完整窗口仍限制在工作区内；没有安全空位时不乱跑。拖动、设置 / 计划窗口打开、隐藏或引光阅读时暂停避让。

后台读取约 1 Hz，主线程只检查小型几何快照。数据超过 3.5 秒未更新时不用于交互。隐藏 / 关闭开关 / 退出时终止自己创建的读取进程并移除快照；后台也检查父程序是否已退出。隔离测试默认不接触真实桌面，真实读取检查须显式启用。

Windows 桌面不可用、图标隐藏或第三方桌面软件没有提供兼容接口时，安静回退到普通悬浮。此功能不是图片识别，不识别任意应用内的图标，也不按文件内容分类。

相关实现：`desktop/icon_awareness.gd`、`desktop/read_desktop_icons.ps1`。PowerShell 通过内存中的自有程序代码启动，不更改执行策略；导出预设显式包含该原始脚本。

## 六个新增动作

原六个动作后追加行走、捧腹大笑、跳跃、连跳、回旋、摇摆；设置页有对应预览入口。主核和玉片仍是刚体，没有增加人体手脚。行走表现为交替踏步，笑表现为玉片向腹侧收拢和连续俯仰，跳跃具有预备、腾空和落地。

全部动作保持悬浮时钟连续，结束归悬浮；回旋补充了随主核旋转的显示覆盖，避免横置玉核被原生窗口裁切。动作控制与图纸说明见 `big-motion-guide.md`。

## 验证

- `test-prototype.ps1`：原回归、图标策略和大动作专项。
- `tests/check_desktop_icons.ps1 -EncodedLaunch`：真实图标矩形、原子快照、桌面不可用、轮询频率与父进程退出。
- `tests/check_icon_reader_runtime.gd`：实际 Godot 后台启动、鲜活快照与禁用后的进程 / 缓存清理。
- `tests/check_growth_render.gd`：成熟粒子下，12 动作、50% / 125%、每动作三个阶段的真实 GPU 像素覆盖。
- `tests/preview_big_motion.gd -- --snapshot`：生成六动作预览 `screenshots/big-motion-v0.11.png`。

安装包与 ZIP 使用相同的最终导出；真实读图标检查仅写临时几何缓存，不包含个人文件名。
