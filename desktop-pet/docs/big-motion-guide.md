# 大幅动作

设置中的「动作预览」现有十二个动作；轻点宠物也会按相同顺序轮换。前六个动作保持原顺序，新增动作如下。

| 动作 | 表现 | 时长 |
| --- | --- | --- |
| 行走 | 玉核左右行进，伴生玉片交替踏步，步点带动轻微起伏 | 6.2 秒 |
| 捧腹大笑 | 玉核连续七轮左右颤动，伴生玉片围在腹部两侧 | 5.4 秒 |
| 跳跃 | 先下沉蓄力，再高高跃起，落地缓冲后悬浮 | 4.4 秒 |
| 连跳 | 三次轻盈起跳，伴随小幅横向移动 | 5.4 秒 |
| 回旋 | 玉核完整回旋再柔和回转，两侧玉片展开护持 | 6.0 秒 |
| 摇摆 | 两轮宽幅左右荡漾，摆动与水平位移配合 | 6.4 秒 |

所有动作从悬浮开始并回到悬浮；悬浮相位和光尘生长持续运行。温玉由三块完整几何体组成，没有新增肢体：动作只改变平移和旋转，不拉伸玉石、不打开玉核。动作区域仍使用 `Rect2(-60, -210, 500, 530)`；回旋使用随玉核旋转的附加原生窗口遮罩，避免横向旋转时裁掉边缘或内部光缝。

验证：使用 Godot 无窗口模式执行 `tests/test_big_motion.gd`，检查动作返回、持续相位、跃起高度、行走范围、大笑反复振动、刚性几何、玉片分离以及旋转后的原生遮罩覆盖。`tests/test_warm_jade.gd` 会遍历全部十二个动作并验证整体区域边界。

图纸：`screenshots/new-motion-blueprint-v0.11.png` 为六个新增动作的三部件轨迹、方向和五个关键姿态；对应的实际运行采样在 `screenshots/new-motion-trajectories-v0.11.json`。通过 `tests/draw_motion_blueprint.gd -- --new-motions` 可复现。六动作表现预览为 `screenshots/big-motion-v0.11.png`。
