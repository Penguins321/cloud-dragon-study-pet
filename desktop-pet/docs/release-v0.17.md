# v0.17：更多形象、动作与回应

日期：2026-10-30。保留温玉灵核与已有学习数据，新增柯基、小鸭、水母三个可保存选择的 3D 伙伴。设置 → 外观 → 陪伴形象切换；预览与桌面加载同一角色场景。

## 形象与交互

玉核动作设计、73 帧动态预览与轨迹验证见 [互动动作细节](expressive-motion-v0.17.md)。

- 三个新角色使用 Gobkit 的真实 GLB 骨骼待机／行走，配合张望、跳跃、庆祝、致意、转圈、起舞等动作组合；攻击和死亡片段不用于陪伴。
- 双击动物致意，附近指针可让闲置角色轻轻转向；拖动优先，放下回待机。专注、安静模式和减少动态继续抑制自主回应。
- 玉核保留材质、颜色、成长、2D/3D 和原动作，另有招手、亲昵、惊喜、小憩；合计 23 个动作。玉核双击招手、中键亲昵、附近左右轻扫可获得回应。
- 动物固定为 3D，界面仅显示适用动作；切回玉核恢复原材质与渲染偏好。旧存档默认玉核，未知角色 ID 安全回退。

## 素材与实现

来源：[Gobkit 作者页](https://gobkit.itch.io/gobkit-free-animal-pack)、[原始清单](https://gobkit.com/api/free)。三个 GLB 均为 CC0，资源直接随应用离线分发。原始文件、许可说明、清单快照和 SHA256 保存在 `pet/skins/animals/models/`；研究和备选取舍见 [资料记录](../../docs/research/2026-10-30-3d-companion-assets.md)。额外动作由应用组合，不能说成素材自带全部片段。

独立透明 SubViewport 渲染角色，使用 alpha 轮廓生成 Windows 显示／点击区域；动作进行时更新轮廓并留安全边缘。隐藏后不持续渲染；换肤销毁旧视口时自动移除待执行的轮廓回调。模型异常退回玉核，旧实例的延迟错误不能覆盖新选择。

## 本机验收证据

- 完整 `test-prototype.ps1`：基础 284 项检查、动作 V13 11,533 项检查；新增动作 235,580 项检查、交互模型 122 项检查；动物、UI、换肤保存恢复与新旧集成均为 0 failures。
- 三个真实骨骼的行走会改变多个关节；各动作结束返回待机，拖动不会被低优先动作打断。
- 18 组实际 GPU 关键姿态：有可见像素，边缘裁切 0、未被输入轮廓覆盖的采样像素 0；九次快速切换与释放无脚本错误。
- 设置页使用生产主场景真实 GPU 渲染，完整柯基可见；隐藏预览暂停推进，23 动作及大字号切换检查通过。
- `scripts/verify-companion-package.gd` 直接读取导出的 Windows EXE，以 NVIDIA OpenGL 实际加载三个角色、骨骼与贴图并渲染，0 failures。
- Windows v0.17 EXE／安装／便携构建采用同一源代码，另附 `GOBKIT-ASSETS.txt`；Mac 导出配置及许可打包同步更新，未在本轮宣称 Mac 真机验收。

本机关键帧与自动输入检查不替代多屏／高 DPI／其他显卡和长时使用验收。当前极短启动阶段在第一张 alpha 轮廓生成前使用保守椭圆。完整回归中的损坏文件和写失败用例会输出预期 ERROR，判定依据为各检查计数及退出码，不能把故障注入日志当成生产错误。
