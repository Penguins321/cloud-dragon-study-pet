# v0.9 设置页与分享安装包

设置页改为独立浅玉 / 暖白主题，不修改右键菜单、计划页或角色表现。自启动、显示大小、动作预览分成三张卡片；百分比和名称共同标记显示档位，六个动作采用三列两行，底部固定显示收起 / 隐藏 / 退出。暂未实现的分享清单与备份恢复占位项不再出现在主设置页。

默认设置窗口为 480 × 660；小窗口保留滚动区和固定底部操作。主题单独存放于 `ui/settings_theme.tres`，不改共享 `study_theme.tres`。自启动与原动作信号保持原接口，开关不写假偏好，失败仍显示实际状态。

可复现截图入口：`tests/preview_startup.gd`。输出默认、360 × 420 小窗口和自启动不可用状态三张截图。回归使用 `test-prototype.ps1`；原测试按“更小”文字查找 50% 按钮，现允许按钮同时包含百分比说明，仍检查真实的 0.5 信号。

Windows 安装包与便携版的构建和测试见`desktop-pet/packaging/README.md`。安装版使用固定的 `WarmJade.exe` 文件名，方便后续升级复用自启动快捷方式。用户学习数据不随安装包分发，保存在当前用户自己的数据目录。
