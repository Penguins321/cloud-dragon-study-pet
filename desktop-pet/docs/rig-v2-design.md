# 云龙 v2：关节动作拆解

历史版本说明：本页保留 v0.3 的结构设计。v0.4 后的尾部、双须、鬃毛和尾焰绑定见 [v3 风动手册](wind-and-tail-v3.md)；玉骨天龙的下一版要求见根目录全身动作规格。

## 本轮目标

左键云龙循环游动、抬头、舒展、收拢和欢腾；任务气泡左键、云龙右键保留学习计划入口。拖动不触发切换。画面需要头颈、长躯干、尾部和四肢配合，不能仅放大整张图片的位移。

## 先拆解，再运动

基准沿用 440 × 178.86179 局部坐标。肩带约 `(331,115)`、骨盆约 `(190,105)`，胸腰通过连续的脊柱关节连接。尾根从骨盆向左延伸，分为尾根、尾中、尾尖与尾焰附着段；颈从肩带向右上延伸至头。两前肢从肩带分支，两后肢从骨盆分支，各有近 / 远侧上肢与下肢。不得把后腿接到尾上、把前腿接到颈上。

使用原图不改像素，建立规则三角网格；Godot Skeleton2D / Bone2D 以静止姿态绑定网格。头面主要跟随头骨刚性运动，躯干相邻骨骼之间平滑权重，腿在关节附近渐变。骨骼父子偏移保持不变，只旋转关节，因此骨段长度不随动作改变。不是随机网格扭曲，也不生成结构不一致的替代帧。

现有原图只有一个可见面，v2 不做翻身、转背、肢体前后交换或盘绕；这些需要重新拆层美术。当前权重是该侧视云龙的绑定，换颜色可复用，换比例 / 四肢位置必须重新绑定。

## 动作规则

- 游动：躯干小幅连续波动，向尾部传递并增大；四肢成对错相划动，头部平稳。
- 抬头：胸腔稳定，颈段先转、头部跟随，尾部保持轻摆。
- 舒展：关节逐渐放开，前后肢向各自合法方向展开，身体弯曲放缓，骨段不缩放。
- 收拢：四肢围绕肩 / 髋向身体收回，颈略低，尾部缓弯；不做自交盘绕，不伪造闭眼。
- 欢腾：上浮配合加强的尾摆和划动，逐渐恢复。拖动时保留抓起反馈。

动作强度参数由版本化 AnimationLibrary 控制。游动相位持续推进，不因每次点击重置，以免尾巴跳帧；参数切换使用短暂混合。原 v1 动作库保留。

## 显示边界与验收

显示轮廓必须使用与 GPU 网格相同的骨骼变换、顶点权重及三角插值，不能继续套用 v1 刚性轮廓。稳定包围框覆盖最大姿态和过渡；每帧拖动仍将整个窗口限制在工作区。测试关节长度、权重归一、相邻三角形不翻转、头部保持比例、尾部相对肩的显著位移、四肢分支、所有动作 / 相位 / 缩放下的透明轮廓覆盖，并在实际渲染中查看。
