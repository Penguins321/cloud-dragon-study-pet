# 云龙动作拆解与结构约束

2026-10-22。先拆解，再增加姿态。现有 PNG 是外观候选，不能当成已通过关节校验的骨架母版。

可复用的关键帧已提取为 `pet/motions/cloud_dragon_float_v1.tres`，换色方法、精确参数、触发与边界规则见 [动作复用手册](action-catalog.md)。

## 身体结构

头 → 颈 → 胸腔 / 肩带 → 长躯干 → 骨盆 → 尾根 → 尾尖是一条连续中心线。两只前肢连接肩带，两只后肢连接骨盆；远侧肢允许被遮挡，但不能改变连接点或凭空消失。角、鬃毛和须附着于头颈，尾焰附着于尾尖。漂浮是世界观设定，不能借此改变骨骼数量和连接关系。

当前素材没有可靠的独立头、肩、骨盆与四肢图层。直接切块拉扯会造成接缝或身体断裂。因此第一阶段采用整身刚性变换，身体各点的相对距离、四肢连接与纹理保持不变。此阶段是动作反馈，不把整体位移称作新的解剖姿态。

## 已接入动作

| 语义 | 设计拆解 | 触发与结束 |
| --- | --- | --- |
| idle | 整身缓慢上下浮动约 4 px，朝向微摆不超过 0.4° | 默认循环 |
| curious | 先微抬身体，再向头部方向轻倾不超过 1.2°，最后恢复 | 打开计划或设置中预览，一次播放 |
| sleepy | 下沉约 5 px，缓慢轻倾后恢复，不伪造闭眼 | 设置中预览，一次播放 |
| celebrate | 两次幅度递减的上浮，最高 12 px，轻倾不超过 1° | 保存完成状态成功后；结束回 idle |
| dragging | 微抬 3 px，轻倾不超过 0.9° | 拖动期间循环，释放回 idle |

所有动作只修改外观根节点的 position / rotation。循环曲线使用平滑插值，动作之间有 0.25 秒过渡，上限 60 FPS；隐藏时暂停。表现层手动推进 AnimationPlayer，再同步原生窗口轮廓，防止图像已移动而裁剪区未移动。皮肤包围框覆盖整套动作，拖动每一帧都限制完整窗口在屏幕工作区内；气泡锚点保持稳定，避免文字跟着抖动。50% 为最小档，轮廓预留整数像素取整余量。

## 下一阶段的三种真正姿态

1. **舒展漂浮**：先画无装饰侧视中心线，颈、胸、腰、骨盆和尾根分别标记；身体曲线变缓，四肢从正确关节向外伸展，尾部有连续弯曲，不复制或拼接身体。
2. **收拢休息**：保持悬浮，中心线轻弯但不交叉；前后肢各自向对应胸腔 / 骨盆收拢，闭眼单独做表情层。不采用未经验证的盘绕图。
3. **警觉抬头**：胸腔不动，颈椎连续抬起，头部跟随颈部；角、须、鬃毛整体附着，不从胸腔长出额外颈段。

每种姿态先输出结构稿与同姿态外观对照，再检查：中心线可追踪、四肢连接一致、头身比例一致、尾根明确、遮挡顺序可解释。用户确认后才拆层制作正式动作。禁止用 PNG 非等比缩放、随机网格扭曲或未经检查的生成帧代替结构设计。

## 扩展边界

学习逻辑只调用语义动作。新皮肤在 `skin.tres` 中映射自己的动画、显示轮廓、稳定包围框和气泡锚点。未来骨架或逐帧动画应由皮肤提供相应轮廓策略；当前 `render_texture / render_rect` 只适用于整身刚性变换，不能直接宣称支持独立肢体变形。
