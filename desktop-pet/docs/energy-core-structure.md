# 温玉灵核：始终以能量核心为主体

用户最终澄清：这是能量核心。每一步修改都必须保持这个初衷；去掉火焰，保留简洁的 3D 主体。

核心验收标准：质感、运动流畅、玄幻、高级。玉体厚度与宽切面、内在暖光与外部冷光必须统一；动作沿用连续轨迹和伴生片的轻微滞后；以克制的悬浮、能量凝聚和共鸣表达玄幻。禁止以新增特效数量、强白光或装饰线密度冒充质感。

结构是三个刚性物件：主玉核、左伴生玉片、右伴生玉片。中央内光表达玉核内部的能量，不是第四块玉石，也不是透明壳里插入一根白色灯条。原始依据为 assets/companions/warm-jade-core/2026-10-26/README.md 和同目录结构示意图。

统一材质关系：
- 玉质载体有厚度、宽切面、温润的反射和少量内在棉絮；避免玻璃外壳、金属锐边和密集装饰线。
- 能量在主核内部形成柔和的暖金/象牙白高密度区，中心略宽、两端收细；经过玉质吸收与散射后可见。能量有明暗层次，不能是一片恒定白色。
- 主核各面应受到内光染色；两枚伴生片保持相同材质，接受核心暖光，但不各自复制一根白光。
- 外部反光随光向/视角变化；内部能量随自身位置、遮挡厚度和动作状态变化。两者不可混为一层。
- 原有动作轨迹和部件数量不变；悬浮能量微弱起伏、收息减弱、共鸣增强，不能以石体胀缩代替能量变化。

实现采用材质内部的简化体积采样与衰减，再与同一玉质表面的受光合成；不宣称真实光线追踪或完整光学折射。验收先看无能量/正常/收息/共鸣，以及正面和侧面，确认不是无光照的独立白色实体。

补充要求：围绕能量核心保留轻盈灵光粒子，沿用 28–72 枚的陪伴成长密度与连续淡入/淡出；使用前后两层 3D 实例呈现空间感，不能恢复火焰。内部光路按每个切面的法线折射，再穿过带吸收的能量体积，增强核心的深度和透射变化。这不包含对其他桌面应用画面的实时扭曲。
