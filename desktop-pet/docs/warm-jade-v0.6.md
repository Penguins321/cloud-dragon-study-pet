# 温玉灵核 v0.6

用户要求直接替换为已选参考形象、增加光影与粒子，动作从悬浮起、结束回悬浮。

沿用 PetSkin / PetView 的语义动作和 AnimationPlayer。以一个菱体和两枚不互换位置的伴生玉片作为三个刚体；切面使用顶点颜色插值，中央象牙白暖金光缝、径向柔光和椭圆投影作为独立表现层。26 枚微粒按持续时钟运动，重生前后渐隐。无需新依赖或新美术生成服务。

每个单次动作的所有偏移参数在首尾均为零；61 个采样键实现 smoothstep 入场与收势。悬浮相位只随时间前进，不受动画切换重置，AnimationPlayer 保留 0.25 秒混合。隐藏时暂停，释放拖动回到悬浮。引光挂点随主核刚体变换，使用已有 5.6 秒目标雾幕。

PetView 为提供 render_regions 的角色使用其运行时视觉轮廓。玉核柔光、伴生片、影子与各粒子分别提供覆盖轮廓，与目标雾幕求并集，保留其他透明空隙。visual_bounds 统一预留所有动作和目标雾幕空间。

验证入口：`test-prototype.ps1`，包含原回归检查与 `tests/test_warm_jade.gd` 的动作回悬浮、相位连续性、部件侧序及完整效果边界检查。预览由 `tests/preview_warm_jade.gd` 使用真实运行皮肤渲染到 `docs/screenshots/warm-jade-poses.png`。桌面实鼠操作、多 DPI、多屏验收不由这些自动检查替代。
