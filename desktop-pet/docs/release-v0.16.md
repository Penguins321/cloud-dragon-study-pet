## 形象与陪伴

- 三种现有材质/颜色搭配提供快捷预设；全部材质、颜色和 19 个动作仍可手动预览。
- 专注时核心内光平稳收敛，停止自主表演和图标避让；状态过渡平滑，晶体不拉伸，也不增加额外石体。
- 自然陪伴在连续闲置 45–90 秒后，低频选择感知/收息/舒展/巡光，避免连续重复；菜单、拖动、面板、手动动作、隐藏或专注时不抢占。解除阻塞/休眠恢复后重新等待完整冷却。
- 安静模式不主动表演；减少动态让基础悬浮和粒子更缓慢。主动点击和预览仍保留。
- 陪伴成长继续从 28 到 72 粒子，只累计可见活跃时间，不因休息/离线倒退。专注统计独立记录。

## 学习与专注

学习页使用清晰的目标/当前项卡片、专注卡和总进度。追加任务、修订当前目标/任务、撤销当前完成均保留原任务 ID 与已有进度；整单替换仍有明确重置确认。完成当前项后，只有主动开始下一项才推进。

专注支持整数 5–120 分钟，默认 25 分钟，可暂停、继续、结束本轮。标签记录开始时的任务标题；改名或推进不会暗中重绑会话。计时结束不自动标记完成或推进任务，也不强制弹窗/播放声音。

隐藏宠物时，已主动开始的专注继续；休眠或超过 2 秒的不连续运行间隙自动暂停，不补算。退出重启后恢复为暂停，手动继续。累计有效专注按实际运行增加，完整会话次数仅在自然归零时增加一次；结束本轮保留已经累计的时间。

## 界面、桌面与帮助

设置与学习页共用浅玉色/暖白卡片和深青正文。设置分为外观、陪伴、桌面、数据与帮助；新增置顶开关、流畅 60 FPS / 节能 30 FPS。隐藏后降低刷新，恢复后沿用用户档位。

四档全局字号覆盖新增控件、实际标签栏、输入框、确认弹窗；页面可滚动，键盘焦点会跟随滚动。修订失败保留输入并在弹窗中显示错误；长导入摘要在有界滚动区内完整显示，确认按钮保持可达。通知可关闭。首次创建示例计划会展示学习页和操作提示，帮助可重看；Escape 可收起面板。

## 数据保护与迁移

设置 → 数据与帮助：

- **导出模板**：目标与任务标题，独立格式 `warmjade-plan` v1，不包含完成进度。
- **导出备份**：计划、任务稳定 ID、当前项和完成状态，格式 `warmjade-plan-backup` v1。
- **导入计划**：文件大小最多 2,000,000 字节；先校验与预览完整目标、任务数量、完成数量，确认后才替换。未知格式/版本、非法值、取消或写入失败不替换当前计划。
- **恢复最近备份 / 恢复导入前计划**：均先预览确认。`.bak` 是前次有效保存；`.before-import` 是最近覆盖前状态，不是无限历史库。
- **打开数据目录**：查看当前存储位置；损坏文件保留，主备均损坏时暂停普通保存并给出说明。

模板与计划备份均不包含外观、位置、成长、专注统计或系统启动配置。后几项继续位于本地 `preferences.cfg`；本轮给它加入 `.tmp` 写入替换与有效 `.bak` 保护，坏主文件可回退；两份均损坏时使用默认值运行并阻止自动覆写。迁移整份本地配置仍需先退出程序，再复制对应用户数据目录。

数据导出禁止覆盖当前学习/偏好及其临时、备份、检查点文件。更新/卸载仍保留用户数据，开机启动仍由用户明确开启。

### 帧时间短测

每种状态使用成熟 72 粒子，预热 120 帧，再分别采样 360 帧悬浮和动作；不在采样中读回 GPU 图像。学习/设置窗口关闭，自主调度关闭以保持样本可比。

| 状态 | 悬浮 FPS / P95 | 动作 FPS / P95 | 两阶段最长帧 |
| --- | --- | --- | --- |
| 流畅 60 FPS | 60.01 / 17.49ms | 60.00 / 17.39ms | 19.15ms |
| 节能 30 FPS | 30.00 / 34.49ms | 30.00 / 34.41ms | 35.74ms |
| 专注 60 FPS | 60.01 / 18.17ms | 60.01 / 17.60ms | 20.46ms |

未出现超过 50ms 的帧。脚本初始化至首帧约 531–552ms，不含进程创建；单独报告，不混入稳态帧时。此结果只代表本机短测；未测量电池功耗，旧机器约 190ms 的偶发长帧仍未复现，不能认定根因已修复。

复现：隔离 `CLOUD_DRAGON_DATA_DIR` 后运行 `res://tests/measure_frame_time.gd`；附加 `-- --eco` 或 `-- --focus`。界面截图入口 `res://tests/preview_v016.gd`；当前角色烟雾入口 `res://tests/smoke.gd`，导出验证使用 `Windows Validation` 预设。原始日志在 `.tools/v016-*`，不提交。
