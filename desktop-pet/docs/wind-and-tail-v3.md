# 云龙风动与尾部规则 · v3

更新：2026-10-22，对应运行原型 v0.4。[v2 身体拆解](rig-v2-design.md)与[动作语义、时间线](action-catalog-v2.md)继续适用；本文件覆盖新增风动和尾部规则。原 v1 / v2 图片与动画库保留归档。

## 结构先于动作

头、肩、骨盆和四肢关系保持不变。新增控制段必须沿同一连续尾部向外延伸，不得用一组彼此无关的旋转图片代替。五个尾部控制段不代表真实动物只有五节尾椎，而是对连续弯曲的控制采样。

| 部位 | 结构 / 绑定坐标（局部 440 × 178.86179） | 运动约束 |
| --- | --- | --- |
| 尾部 | 尾根 `(137,123)` → 内段 `(110,127)` → 中段 `(80,125)` → 外段 `(55,113)` → 尾梢 `(32,86)` | 父子顺序传动，骨段不缩放；骨盆带动尾根，不接到后腿 |
| 尾焰 | 焰根 `(29,80)` 接尾梢；焰身 `(31,62)` → 主焰尖 `(34,40)` | 根部跟随尾端，焰身和焰尖相对根部弯动 |
| 左侧火舌 | 焰身 → `(21,64)` → `(12,52)` | 与主焰错相，末端较快的小卷动 |
| 右侧火舌 | 焰身 → `(43,65)` → `(49,57)` | 与左束节奏不同，避免整团同步摇摆 |
| 右须 | 头 → `(411,53)` → `(427,63)` → `(423,79)` → `(434,96)` | 须根不摇脱，波动向末端传递 |
| 左须 | 头 → `(376,49)` → `(354,54)` → `(337,71)` → `(316,88)` | 同上；原图与鬃毛重叠，使用更宽的渐变过渡避免抬头时翻折 |
| 鬃毛 | 头 → `(362,36)` → `(333,43)` | 只作用于后掠软毛区；金角和眼鼻不纳入新风动影响场 |

当前共 36 个控制关节；继续使用 55 × 30 网格、3,300 个三角形、每顶点最多四个归一化权重。为保留旧关节 ID，后来加入的中间尾节 ID 可以大于子节点；创建和计算使用父节点优先的拓扑顺序，不能再假设 ID 天然排序。

## 节奏与参数

相位 `phase` 持续累计，以 `swim_speed` 控制速度，不因左键切换动作归零。所有风动乘以校准后的 `swim_strength`，所以同一动作库可控制漂浮、游动、收拢和欢腾中的强弱。隐藏时暂停相位；恢复后继续原有节奏。动作参数混合仍为 0.25 秒。

- 尾根至尾梢的主波延迟依次为 1.8 / 2.1 / 2.4 / 2.7 / 3.0 弧度，基础幅度为 6 / 5 / 7 / 6 / 8 度，并叠加很小的二次谐波。总弯曲预算接近 v2；细分不意味着把每段都旋转原来的大角度。
- 龙须每段延迟 0.65 弧度，右须主波 12 度、附加波 3 度，左须为 7 / 2 度且整体错相。根段保持零额外转角，末端由父链与自身转动共同产生飘动。
- 鬃毛主波 4 度、附加波 1.5 度。避免头、须、毛、焰完全同相，形成轻重与跟随层次。
- 焰身、主焰尖和左右火舌使用不同的二、三次谐波；火舌较快、尾部较慢。周期均使用整数谐波，跨越相位首尾时位置和速度连续。
- 尾焰材质只改变局部 RGB 明暗，幅度约 ±13% × strength，保留源 alpha。参数来自显式相位，不用持续运行的全局 TIME，保证隐藏暂停、离线导出与预览可复现。CanvasItem 的片元 COLOR 已包含纹理和调制色，不能再重复乘一次贴图，依据 [Godot 官方说明](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/canvas_item_shader.html#color-and-texture)。

精确公式以 `pet/skins/cloud_dragon/rig.gd` 与 `flame.gdshader` 为准。这里是可复用的艺术控制规则，不宣称流体仿真。当前尾焰实现包含分束变形与亮度起伏，尚没有粒子的生成、脱离和消散生命周期。

## 换色、换形与玉骨天龙

仅换色继续共享 `cloud_dragon_flexible_v2.tres`、骨架脚本和尾焰 Shader；不复制动作关键帧。每个实例使用独立 ShaderMaterial，颜色仍由 Illustration 的 RGB 调制或替换贴图决定。`render_texture` 需同步为实际贴图。

用户已选择新美术 **C 玉骨天龙**，定向稿、结构拆解与提示词见根目录 [美术归档](../../assets/cloud-dragon/redesigns/2026-10-22-jade-dragon/README.md)。新形象更换了比例、角型、鳞甲和尾焰，不能直接把新图压到旧权重上。接入顺序：

1. 以选定完整形体确定侧面中线、肩、骨盆、四肢和须根；核对近远侧遮挡。
2. 制作透明主躯干与独立双须、鬃毛、焰根、焰身、各束火舌，硬质骨角 / 鳞甲与柔性层分开；为遮挡后区域补画底图。
3. 标注各控制链并重新绑定；动作语义、相位、延迟规则和控件接口继续复用，坐标与权重不直接复用。
4. 先测试慢速单条尾波，再叠加火舌与明暗；按 50% 尺寸检查轮廓和可读性，最后检查过渡及原生窗口裁剪。

定向稿中的风向箭头只表示气流，不能把画在骨角附近的箭头解释为骨角可以柔性弯折。细化稿尚非已通过绑定验收的运行皮肤。
