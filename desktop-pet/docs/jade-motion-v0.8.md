# v0.8 水晶玉核与全动作轨迹

引光已从旧龙喷气烟雾改为独立的“聚光成笺”：蓄光、光点牵引、切角玉色光笺展开、真实目标阅读、收光，5.6 秒结束回悬浮。旧龙仍保留其原效果。新的光笺沿用文字布局与计划入口，不使用云雾噪声材质，不常驻。

形象增加透明度、青玉至冰蓝顶点渐变、内层晶面、动态掠光与亮边。采用风格化透明绘制，不代表真实光学折射模拟。三个石体保持刚性，不变形，不增加新碎片。

| 动作 | 时间 | 动作区别与控制量 |
| --- | --- | --- |
| 悬浮 | 4.8 s 循环 | 主核上下约 ±8 px，玉片错相悬浮 |
| 巡游 | 5.8 s | 双向横移、两次纵向弧线，横向参数峰值 ±58 px，倾斜随转向改变 |
| 感知 | 4.6 s | 左探、右探、回正，倾斜参数约 ±14°，微移配合 |
| 舒展 | 4.8 s | 主核上升 28 px，两片各向外展开 44 px，展开时外旋 |
| 收息 | 4.8 s | 主核下沉 25 px，两片各内收 19 px，内光变暗 |
| 共鸣 | 5.2 s | 两次升降和展开脉冲，主核上升参数约 37 px，小幅横摆 |
| 引光 | 5.6 s | 保持接近正立，上抬 20 px，两片各展开 30 px，光笺随时间展开 / 消失 |
| 牵引 | 随鼠标 | 拖动保持轻收，释放后混合回悬浮；图中只展示固定鼠标下的跟随 / 释放归位 |

以上为动作控制量，实际轨迹叠加持续悬浮。伴生片分别约 70 / 120 ms 滞后主核；首尾回到悬浮状态，不强制归零悬浮相位。单次动作结束自动切回 idle。
