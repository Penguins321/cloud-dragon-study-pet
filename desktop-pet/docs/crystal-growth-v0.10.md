# v0.10 晶纹与粒子成长

本次按用户最终决定：直接增强玉核内部晶纹、通透层次和折光，保留现有辨识度。成长仅表现为周围光粒更多、更明亮，不再逐级改变形体或材质。

## 表现

原主核与左右玉片的几何、枢轴、动作均保留。前层玉色切面更通透，内部增加细分支晶纹、偏移的后层晶面与冷暖折光扫光。采用风格化分层透明绘制，不是光线追踪折射。

初始 28 枚光粒；累计 20 小时约 50 枚；40 小时达到 72 枚上限。粒子数量、亮度、光晕与星芒连续增强，新增光粒逐渐出现。粒子运动相位保持连续，没有等级弹窗、声音或成长惩罚。

40 小时是本轮采用的默认成长节奏，便于一周左右的上班陪伴逐渐观察到变化。超过上限继续记录总有效时长，粒子不会无限增加；未使用不会退化。

## 计时与保存

在既有 `preferences.cfg` 的 `[companionship] active_seconds` 中保存，不修改学习清单，也不重置其他设置。每累计 60 秒有效运行保存一次，主动退出时再保存。异常强制结束最多可能丢失最近约一分钟。

宠物隐藏 / 最小化到托盘时不累计。帧增量非法或超过 2 秒时忽略，另检查单调时钟的挂起间隔，避免引擎恢复时把休眠时间当作陪伴。离线没有补算。

## 验证入口

- `tests/test_companionship.gd`：模型恢复、无效数据、隐藏 / 挂起、单调成长与进度上限。
- `tests/test_crystal_growth.gd`：粒子逐渐增加、72 枚上限、形体不变、成熟视觉边界。
- `tests/check_growth_persistence.gd`：实际主程序加载 20 小时存档、应用 50 粒子、写回与保留其他设置。
- `tests/check_growth_render.gd`：真实 GPU 渲染六个动作、三阶段、50% / 125% 缩放，检查原生窗口轮廓覆盖。
- `tests/preview_growth.gd`：生成初始 / 中期 / 成熟的同姿态对照图 `screenshots/crystal-growth-v0.10.png`。

显示与点击轮廓对内层粒子复用已有柔光覆盖，对外层光粒补充小轮廓；成长不会生成 72 个冗余布尔并集。

本次不包含此前讨论的整点出现、投喂等其他桌宠行为。
