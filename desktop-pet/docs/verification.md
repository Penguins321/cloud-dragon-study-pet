## 动画帧率实测与限制

v0.2 修复过粗略轮廓和两两连接的性能问题；v0.3 增加真实关节变形后，CPU 采样的关节更新约 0.08 ms，轮廓映射约 3.1 ms，不能直接用这些 CPU 时间推断最终帧率。主窗口保留引擎 60 FPS 限制，关闭额外 GL VSync 等待，避免当前透明窗口在 Intel / Windows 上跌至半刷新率。动作混合 0.25 秒，隐藏时暂停相位与动画。

最终生产配置短时样本：预热 3 秒后统计 360 个 `RenderingServer.frame_post_draw` 间隔，耗时 6.159018 秒，平均 **58.45 FPS**，P95 **19.70 ms**，最长 **148.64 ms**。这是当前机器的一次短样本，仍存在偶发长帧，不能声称已稳定锁定 60 FPS 或完全无卡顿。

v0.2 对照中固定矩形轮廓仍出现约 138 ms 长帧；本轮开启原 GL VSync 时一段样本约 26.10 FPS，关闭后的对照约 58.88 FPS，最终生产配置约 58.45 FPS。短样本不能证明所有停顿都来自 VSync，仍需追踪偶发长帧。后续应在其他电脑、显卡 / 渲染链及真实拖动中继续定位。旧静态版本的启动 CPU / 内存样本不能作为本动画版本的占用结论；本轮未完成长期 CPU / GPU / 内存测量。

复现帧率：在根目录 PowerShell 执行以下命令。所有数据独立，脚本自动退出：

```powershell
$env:APPDATA = Join-Path (Get-Location) '.tools/appdata'
$env:CLOUD_DRAGON_DATA_DIR = Join-Path (Get-Location) '.tools/frame-check'
& '.tools/godot-4.7.2/Godot_v4.7.2-stable_win64_console.exe' --path desktop-pet --quit-after 1200 --script res://tests/measure_motion.gd
```

真实渲染烟雾测试将最后的 `--script` 改为 `res://tests/smoke.gd`，同样必须保留隔离数据目录。可选 `CLOUD_DRAGON_SCREENSHOTS` 设置截图目录。普通启动请开新终端或清除这些测试环境变量，以免继续使用测试数据。
