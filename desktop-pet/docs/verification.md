## 审查与修复

独立只读审查发现三个 Important：多实例旧快照覆盖数据、左边缘面板遮住宠物、凸包拦截透明空隙。分别增加失败回归并修复；新增检查曾出现 4 failures，修复后通过。

动作缺失导致低优先级请求退出拖拽的问题，因其违反未来皮肤模块的优先级承诺，重新定级为 Important 并在同一修复阶段处理；对应检查已观察到失败并修复。没有待办的审查 Minor。

原生主窗口不能直接 `hide()` 的问题在真实渲染检查中发现，已改为最小化至托盘，并添加主窗口模式断言。headless 不能验证原生窗口模式，因此此项仅在真实 OpenGL 检查。

## 资源占用短时样本

启动后短时采样约 2.0 秒，静态原型工作集约 203.6 MiB，CPU 约占一个逻辑核心的 15.46%（机器 16 个逻辑处理器，约为全机 0.97%）。帮助程序以 Hidden 方式启动，样本包含启动后的短时活动，不能代表长期闲置水平，也不能与任务管理器的不同统计口径直接比较。

原始数据：父项目 `docs/superpowers/execution/resource-metrics.json`。GPU 使用率、动画状态及稳定托盘隐藏状态未测，正式动作尚未制作，不编造动画测量数据。资源优化留待后续常驻体验验证。

## 架构取舍

单实例锁使用绑定至 127.0.0.1 的进程生命周期 TCP 监听，不发送任务数据。按规范化数据目录哈希选择端口；不同目录或其他本地程序可能发生端口碰撞，此时安全拒绝启动，避免并发写。后续产品化可换成 Windows 原生命名互斥量。
